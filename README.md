# whynot-skills

Наборы навыков для вашего ИИ-агента. Ставятся в один клик, работают у вас на компьютере.

Здесь три независимых плагина:

| Плагин | Отвечает на вопрос |
|---|---|
| **Видео: от записи до публикации** (`montazh`) | **как** сделать из моего видео ролик и выложить его |
| **Съёмка процесса → рилс** (`process-reel`) | у меня час съёмки **без слов** — как достать из него 30 секунд |
| **О чём снимать и публиковать** (`content-tseh`) | **что** публиковать и почему это посмотрят |

Берите тот, что нужен. Съёмка процесса вынесена отдельно не случайно: там другой метод
отбора и он нужен не всем — художникам, керамистам, мастерам маникюра, реставраторам.

## Сколько это весит в разговоре

Вопрос, который задают первым: «агент будет читать все навыки каждый раз?» Нет.

**Постоянно в контексте висят только описания** — по 200–260 токенов на навык. Агент
знает, что навык есть и когда он нужен, но не читает его. На сегодня: видео-набор
**~1 970**, съёмка процесса **~200**, «о чём снимать» **~1 100**. Свежую цифру всегда
покажет `claude plugin details <плагин>`.

**Тело навыка читается только когда он сработал** — и здесь работает архитектура:
большой метод разложен на короткий индекс и справочники, которые подтягиваются по ходу.

| | было | стало |
|---|---|---|
| съёмка процесса, метод на 900 строк | 19,9k одним куском | **2,3k** индекс + справочники по надобности |
| монтаж своего дубля | 3,8k | **2,5k** |

Справочники устроены так: в индексе таблица «что читать когда» — метрики и пороги
отдельно, сборка и ритм отдельно, докачка из облака отдельно. До докачки большинство
не доходит никогда, и она не стоит ничего.

## Видео: от записи до публикации

Девять навыков и один агент. Он сам понимает, какой у вас случай:

| Что у вас есть | Что получите |
|---|---|
| **длинная запись с речью** — вебинар, эфир, созвон, подкаст | 3–5 коротких вертикальных роликов с субтитрами: агент расшифрует запись, найдёт куски, где мысль начинается и заканчивается, и порежет их |
| **свой дубль или несколько подходов к одной мысли** | готовый ролик: агент **выберет дубль по темпу речи** (на живой съёмке два дубля дали 197 и 168 слов/мин — разница слышна сразу), уберёт паузы между фразами **и внутри фраз**, фальстарты и повторы, вычистит звук, поставит крупный хук и пословные субтитры. Плюс **A/B-варианты заголовка** из одного тела — второй вариант почти бесплатный |
| **длинное видео для YouTube** — 5–20 минут | почищенный звук, мусор из речи убран, блоки склеены **по смыслу** (а не по порядку записи), интро-хук, главы с таймкодами, субтитры отдельным файлом `.srt`. Паузы здесь не режутся плотно — длинному нужно дыхание |
| **готовый ролик** | публикация в Instagram, TikTok, YouTube, Threads, Telegram и другие — через ваш аккаунт, на лучшее время |
| **не знаете, с чего начать** | дорожка: тема → сценарий → съёмка → монтаж → первый экран → публикация → разбор. Состояние лежит в файле, поэтому «а на чём мы остановились?» больше не вопрос |

**Графика — три уровня, по возрастанию цены:**

- **карточки-плашки** с текстом или кодом: тёмное окно, шапка, номер шага, выезд и фейд.
  Работает на ffmpeg, ставить нечего;
- **вставки и b-roll**: подбор под произнесённую фразу из ваших же скриншотов, посадка
  **на границу фразы**, кадрирование внутри аккуратной карточки. Плюс **библиотека, которая
  копится между роликами** — реестр по ключевым словам, чтобы в следующий раз не
  переснимать то же окно. Это единственная часть работы, которая идёт на сложных процентах;
- **сложная моушен-графика** — карточка на каждую фразу, караоке-субтитры по словам,
  счётчики на цифрах. Ставится отдельной командой, требует Node.js и имеет
  лицензионное условие (см. ниже). Без неё набор полноценен.

**Мастер первого запуска** доводит от «поставил плагин» до первого собранного ролика
на вашем же файле: сам скачивает ffmpeg без пароля администратора, заводит папки,
проверяет связь с сетями.

### Установка

#### Claude Code

**В приложении:** Customize → Plugins → Add marketplace → вставьте `LenaWhynot/whynot-skills`
→ Install у плагина «Видео: от записи до публикации».

**В терминале:**

```
/plugin marketplace add LenaWhynot/whynot-skills
/plugin install montazh@whynot-skills
```

Снести — там же, кнопкой Uninstall.

#### Codex

Codex плагины Claude Code не читает, но навыки понимает. Одна команда в терминале:

```
curl -fsSL https://raw.githubusercontent.com/LenaWhynot/whynot-skills/main/install-codex.sh -o install-codex.sh && bash install-codex.sh
```

Скрипт скачает навыки, положит их в папку Codex и перепишет пути под него.
Ставить ffmpeg и что-либо ещё руками не нужно — это сделает мастер настройки.

Снести: `bash install-codex.sh --remove` — уберёт только эти пять навыков,
остальное в Codex не тронет.

Две вещи про Codex, чтобы не удивляться:

- В нём есть **свой** навык распознавания речи, `transcribe` от OpenAI. Если агент
  ушёл не туда, позовите нужный прямо: «нарежь роликов навыком video-clips-from-talk».
- Монтажёр-распределитель в Codex работает навыком, а не субагентом: скажите
  «настрой монтажёра» или «нарежь роликов из записи» — он сам разберётся,
  есть в записи речь или нет.

### Как пользоваться

Никаких команд. Скажите агенту своими словами:

> настрой монтаж

> нарежь мне роликов из этой записи

> собери ролик из этого дубля, убери паузы

> собери рилс из этой съёмки

> поставь карточку на эту фразу

> подбери вставки под текст

> поставь этот ролик в инстаграм и тикток на лучшее время

> проведи меня по шагам — на чём мы остановились?

Начните с первого — мастер настройки доведёт до готовности и прогонит весь путь
на вашем же файле. Дальше агент сам понимает по словам, какой навык нужен.

### Что нужно на компьютере

- **ffmpeg** — обязателен для монтажа. **Ставить руками не нужно:** мастер настройки
  скачает его сам, без Homebrew и без пароля администратора.
- **Python-пакеты** — по мере надобности, одной строкой: `faster-whisper` для расшифровки
  речи, `pillow` и `numpy` для карточек. Ядро монтажа работает на одном ffmpeg.
- **Node.js** — только если нужна сложная моушен-графика. ⚠️ **Лицензия Remotion:**
  он бесплатен для физических лиц и компаний до 3 сотрудников, компаниям больше нужна
  платная Company License. Набор его не ставит и не решает это за вас; остальные навыки
  таких требований не имеют.
- **Взгляд в камеру** умеет мериться по зрачку, но этот измеритель работает только
  на macOS. Без него работает всё остальное.
- **Распознавание речи** — только для записей с речью. Агент спросит, каким путём идти:
  локально (бесплатно, качается один раз) или через облако (платно по минутам, зато сразу).
- **numpy** — только для съёмки процесса без речи, там на нём считается отбор кадров.
  Ставится одной строкой, агент сделает это сам: `python3 -m pip install --user numpy`.
- **Для публикации** — два бесплатных коннектора (Metricool и Google Drive) плюс
  программа Google Drive для десктопа. Мастер настройки доведёт до нужных экранов;
  логин вы делаете сами, паролей агент не спрашивает никогда.

Видео никуда не заливается: вся работа идёт на вашем компьютере. Наружу уходит только
то, что вы отправляете в публикацию, — в ваше собственное облако и ваши соцсети,
и только после того, как вы сказали «да». Исключение — если вы сами выберете облачное
распознавание, тогда аудио уходит в тот сервис, чей ключ вы дали.

### Сколько это стоит — монтаж и публикация

Подписка на ИИ — и всё. Публикация по умолчанию идёт через **бесплатный** тариф
Metricool: 20 постов в месяц, Instagram, TikTok, YouTube, Threads, Facebook и другие.

Нужен **Telegram** — его Metricool не умеет вообще, зато он закрывается
**полностью бесплатно**: свой бот в свой канал, настройка пять минут, лимита на
число постов нет. Ни сервиса, ни сервера, ни подписки.

Instagram тоже умеет **напрямую, без посредника и без одобрения Meta** — тогда
вместо 20 постов в месяц доступно 50–100 в сутки. Цена: токен надо обновлять
(агент ставит сторож, который делает это сам) и нужно своё место, куда положить файл.

Хотите много площадок в одном календаре — есть рельс Postiz (открытый исходный код,
33 площадки), но он тянет свой сервер или от $29/мес. Не хотите ничего заводить —
публикуете руками, агент готовит подписи, время и порядок действий.

**TikTok** публикуется только через Metricool: собственного пути туда нет ни у кого,
там обязательный аудит со стороны TikTok.
## Съёмка процесса → рилс

Для тех, кто снимает **работу руками без слов**: художник рисует, керамист лепит,
реставратор чистит, мастер делает маникюр, повар готовит.

Из часа съёмки в ролик попадает **20–30 секунд**. Отбраковка 97–99,6%, и вся ценность
в отборе — он двухслойный:

1. **Статистика сужает.** Сплошной проход по кадрам считает тряску, работу руки,
   резкость, движение в фоне и то, изменилась ли сама работа. Остаётся 40–60 кандидатов.
2. **Глаза выбирают.** Кандидаты отсматриваются **полосами кадров** — по одному кадру
   брак не виден: в середине куска картинка идеальная, а через полсекунды в кадр въезжает
   голова или проносится смазанная рука.

Пороги — **перцентили вашего материала**, а не абсолютные числа: настроенные на одном
сюжете, на другом отсекают почти всё. Внутри восемь готовых анализаторов, стабилизация,
формат раскладки и отдельные разделы про ловушки: `rotation` в метаданных, врущая
перемотка по HTTP, маркер в цвет поверхности, таймлапс, оборванный на мёртвом кадре.

**Установка:**

```
/plugin install process-reel@whynot-skills
```

**Что нужно:** ffmpeg (мастер поставит сам, без пароля администратора) и `numpy`
одной строкой. Библиотека метода разложена по справочникам и читается по ходу —
в разговор не тащится всё сразу.

**Как пользоваться:**

> собери рилс из этой съёмки

> нарежь из часа видео

> смонтируй как монтажёр

## О чём снимать и публиковать

Пять навыков. Отвечает не на «как смонтировать», а на **«что публиковать и почему это
посмотрят»**:

- **Разведка ниши.** Кто снимает про вашу тему прямо сейчас и что у них залетает:
  свежие ролики по словам, отсортированные по просмотрам, с отношением комментариев
  к лайкам (больше единицы — почти всегда воронка «напиши слово в комментарии»).
  Отвечает на вопрос, который руками не решается: соцсеть не отдаёт ленту по слову
  без логина. Нужен бесплатный аккаунт Apify — $5 в месяц даются бесплатно, рабочий
  режим укладывается в $1,70. Разведка находит кандидатов, разбирает их следующий навык.
- **Темы из вопросов людей.** Комментарии, личка, записи созвонов → карта болей,
  желаний и возражений, живые формулировки и темы с форматом под каждую.
  Если входа нет, агент так и скажет, а не выдумает «боль аудитории».
- **Серия под одну тему.** Одна тема → 3–10 материалов с разными задачами: ошибка,
  доказательство, разбор, история, возражение, приглашение. Не пять способов сказать одно.
- **Первый экран.** Обложка видео, превью, титульный слайд: три концепта и бриф на
  выбранный. С проверкой миниатюрой — как это выглядит размером с ноготь в ленте.
- **Текст на экран.** Подписи по ходу ролика, чтобы он был понятен без звука.
  С тестом на mute и с ограничениями кадра, о которых забывают: низ закрыт интерфейсом,
  текст не должен ложиться на лицо.
- **Разбор чужого видео.** Ссылка на удачный ролик, вебинар или карусель → что сработало,
  как это устроено и как перенести на себя. Отдельно — слой продажи: куда ведёт ссылка,
  где внутри стоит оффер, на чём держится модель автора и переносима ли она.

**Чего он не делает:** не пишет тексты вместо вас. Вашего голоса в наборе нет —
и подделка звучала бы как любой ИИ-пост. Он собирает всё вокруг текста, а слова ваши.

**Установка:** Install у плагина «О чём снимать и публиковать», или в терминале:

```
/plugin install content-tseh@whynot-skills
```

Ничего ставить на компьютер не нужно. Исключение — разбор чужого видео: ему нужны
`yt-dlp` и `ffmpeg`, а для расшифровки речи ещё и whisper; агент скажет, чего не хватает.

**Как пользоваться** — своими словами:

> о чём мне писать, вот комментарии под последним постом

> нужна серия к запуску на следующей неделе

> сделай обложку для этого видео

> вот ссылка, разбери и скажи, что забрать

## Как обновиться

Навыки дописываются: правится метод, добавляются инструменты. У вас лежит тот срез,
который был на момент установки, — обновление приходит только по вашей команде.

**В приложении:** Customize → Plugins → Update у нужного плагина.

**В терминале** — две команды, сначала обновляется список, потом сам плагин:

```
claude plugin marketplace update whynot-skills
claude plugin update montazh@whynot-skills
claude plugin update process-reel@whynot-skills
claude plugin update content-tseh@whynot-skills
```

После второй перезапустите Claude Code — иначе старая версия останется в уже
открытых сессиях. Проверить, что приехало: `claude plugin list`.

**В Codex** — запустите установщик снова, он перезапишет навыки
(`--video` или `--temy`, если нужен только один набор):

```
curl -fsSL https://raw.githubusercontent.com/LenaWhynot/whynot-skills/main/install-codex.sh -o install-codex.sh && bash install-codex.sh
```
