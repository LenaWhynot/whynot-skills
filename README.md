# whynot-skills

Наборы навыков для вашего ИИ-агента. Ставятся в один клик, работают у вас на компьютере.

Здесь три независимых плагина — берите нужный или все:

| Плагин | Для чего |
|---|---|
| **Агент по монтажу** (`montazh`) | длинная запись → короткие вертикальные ролики → публикация |
| **Контент-цех** (`content-tseh`) | о чём публиковать: темы, серии, первые экраны, разбор чужих удачных видео |
| **Контент-завод** (`content-zavod`) | своя запись → готовый ролик: дубли, паузы, звук, хук, субтитры, карточки-вставки |

## Агент по монтажу

Четыре навыка:

- **Запись с речью → короткие ролики.** Вебинар, эфир, созвон, интервью. Агент
  расшифровывает запись, находит куски, где мысль начинается и заканчивается,
  режет их вертикально и вшивает субтитры.
- **Съёмка процесса → рилс.** Час съёмки, где вы что-то делаете руками и молчите:
  готовите, рисуете, чините, лепите, реставрируете. Агент отбирает секунды, где
  действительно красиво, и собирает из них ритмичный вертикальный ролик.
  В деле идут 20–30 секунд из часа — вся работа в отборе, и он двухслойный:
  сначала считаются признаки каждого кадра (тряска, работает ли рука, изменилась ли
  картинка, не лезет ли кто в фон), потом кандидаты отсматриваются глазами полосами
  кадров. Метод и пороги выведены из принятых роликов, а не из общих советов.
- **Готовый ролик → соцсети.** Instagram, TikTok, YouTube, Threads, Facebook и другие —
  одним разом, на лучшее время. Через ваш собственный аккаунт: ролик уезжает в ваше
  облако и оттуда публикуется. Ничего не уходит на чужой сервер.
  Сервис публикации **сменный**, а если вы не хотите заводить ни одного —
  агент подготовит всё для публикации руками: подпись под каждую площадку,
  время, порядок действий и файл на телефоне.
- **Мастер первого запуска.** Ставит всё недостающее сам, заводит папки, проверяет
  связь и прогоняет весь путь на вашем файле.

### Установка

#### Claude Code

**В приложении:** Customize → Plugins → Add marketplace → вставьте `LenaWhynot/whynot-skills`
→ Install у плагина «Монтаж видео».

**В терминале:**

```
/plugin marketplace add LenaWhynot/whynot-skills
/plugin install montazh@whynot-skills
```

Снести — там же, кнопкой Uninstall.

#### Codex

Codex плагины Claude Code не читает, но навыки понимает. Одна команда в терминале:

```
curl -fsSL https://raw.githubusercontent.com/LenaWhynot/whynot-skills/main/install-codex.sh -o install-codex.sh && bash install-codex.sh
```

Скрипт скачает навыки, положит их в папку Codex и перепишет пути под него.
Ставить ffmpeg и что-либо ещё руками не нужно — это сделает мастер настройки.

Снести: `bash install-codex.sh --remove` — уберёт только эти пять навыков,
остальное в Codex не тронет.

Две вещи про Codex, чтобы не удивляться:

- В нём есть **свой** навык распознавания речи, `transcribe` от OpenAI. Если агент
  ушёл не туда, позовите нужный прямо: «нарежь роликов навыком video-clips-from-talk».
- Монтажёр-распределитель в Codex работает навыком, а не субагентом: скажите
  «настрой монтажёра» или «нарежь роликов из записи» — он сам разберётся,
  есть в записи речь или нет.

### Как пользоваться

Никаких команд. Скажите агенту своими словами:

> настрой монтажёра

> нарежь мне роликов из этой записи

> собери рилс из этой съёмки

> поставь этот ролик в инстаграм и тикток на лучшее время

Начните с первого — мастер настройки доведёт до готовности и прогонит весь путь
на вашем же файле. Дальше агент сам понимает по словам, какой навык нужен.

### Что нужно на компьютере

- **ffmpeg** — обязателен для монтажа. **Ставить руками не нужно:** мастер настройки
  скачает его сам, без Homebrew и без пароля администратора.
- **Распознавание речи** — только для записей с речью. Агент спросит, каким путём идти:
  локально (бесплатно, качается один раз) или через облако (платно по минутам, зато сразу).
- **numpy** — только для съёмки процесса без речи, там на нём считается отбор кадров.
  Ставится одной строкой, агент сделает это сам: `python3 -m pip install --user numpy`.
- **Для публикации** — два бесплатных коннектора (Metricool и Google Drive) плюс
  программа Google Drive для десктопа. Мастер настройки доведёт до нужных экранов;
  логин вы делаете сами, паролей агент не спрашивает никогда.

Видео никуда не заливается: вся работа идёт на вашем компьютере. Наружу уходит только
то, что вы отправляете в публикацию, — в ваше собственное облако и ваши соцсети,
и только после того, как вы сказали «да». Исключение — если вы сами выберете облачное
распознавание, тогда аудио уходит в тот сервис, чей ключ вы дали.

### Сколько это стоит — монтаж и публикация

Подписка на ИИ — и всё. Публикация по умолчанию идёт через **бесплатный** тариф
Metricool: 20 постов в месяц, Instagram, TikTok, YouTube, Threads, Facebook и другие.

Нужен **Telegram** — его Metricool не умеет вообще, зато он закрывается
**полностью бесплатно**: свой бот в свой канал, настройка пять минут, лимита на
число постов нет. Ни сервиса, ни сервера, ни подписки.

Instagram тоже умеет **напрямую, без посредника и без одобрения Meta** — тогда
вместо 20 постов в месяц доступно 50–100 в сутки. Цена: токен надо обновлять
(агент ставит сторож, который делает это сам) и нужно своё место, куда положить файл.

Хотите много площадок в одном календаре — есть рельс Postiz (открытый исходный код,
33 площадки), но он тянет свой сервер или от $29/мес. Не хотите ничего заводить —
публикуете руками, агент готовит подписи, время и порядок действий.

**TikTok** публикуется только через Metricool: собственного пути туда нет ни у кого,
там обязательный аудит со стороны TikTok.
## Контент-цех

Пять навыков. Отвечает не на «как смонтировать», а на **«что публиковать и почему это
посмотрят»**:

- **Темы из вопросов людей.** Комментарии, личка, записи созвонов → карта болей,
  желаний и возражений, живые формулировки и темы с форматом под каждую.
  Если входа нет, агент так и скажет, а не выдумает «боль аудитории».
- **Серия под одну тему.** Одна тема → 3–10 материалов с разными задачами: ошибка,
  доказательство, разбор, история, возражение, приглашение. Не пять способов сказать одно.
- **Первый экран.** Обложка видео, превью, титульный слайд: три концепта и бриф на
  выбранный. С проверкой миниатюрой — как это выглядит размером с ноготь в ленте.
- **Текст на экран.** Подписи по ходу ролика, чтобы он был понятен без звука.
  С тестом на mute и с ограничениями кадра, о которых забывают: низ закрыт интерфейсом,
  текст не должен ложиться на лицо.
- **Разбор чужого видео.** Ссылка на удачный ролик, вебинар или карусель → что сработало,
  как это устроено и как перенести на себя. Отдельно — слой продажи: куда ведёт ссылка,
  где внутри стоит оффер, на чём держится модель автора и переносима ли она.

**Чего он не делает:** не пишет тексты вместо вас. Вашего голоса в наборе нет —
и подделка звучала бы как любой ИИ-пост. Он собирает всё вокруг текста, а слова ваши.

**Установка:** там же, где и монтаж, — Install у плагина «Контент-цех», или в терминале:

```
/plugin install content-tseh@whynot-skills
```

Ничего ставить на компьютер не нужно. Исключение — разбор чужого видео: ему нужны
`yt-dlp` и `ffmpeg`, а для расшифровки речи ещё и whisper; агент скажет, чего не хватает.

**Сколько это «весит» в разговоре.** Постоянно в контексте висят только описания навыков —
примерно **1 100 токенов** на весь набор (`claude plugin details content-tseh` покажет
свежую цифру). Сам навык читается целиком только когда сработал: от 900 токенов
у экранного текста до 3 500 у разбора чужого видео.

**Как пользоваться** — своими словами:

> о чём мне писать, вот комментарии под последним постом

> нужна серия к запуску на следующей неделе

> сделай обложку для этого видео

> вот ссылка, разбери и скажи, что забрать

## Контент-завод

Для тех, кто снимает **себя**: записал на телефон — получил готовый ролик.
Четыре навыка и агент, который помнит, на каком шаге вы остановились.

- **Мастер первого запуска.** Ставит ffmpeg без пароля администратора, проверяет
  остальное, заводит папку заказа и прогоняет весь путь на вашем же файле.
  Настройка считается законченной, когда собран первый ролик, а не когда «всё скачано».
- **Ролик из дубля.** Записали три подхода к одной мысли — агент **выберет дубль по темпу
  речи** (на живой съёмке два дубля дали 197 и 168 слов/мин: разница слышна сразу),
  вырежет паузы между фразами **и внутри фраз**, уберёт фальстарты и повторы, вычистит
  звук, поставит крупный хук и пословные субтитры. Из одного тела соберёт
  **A/B-варианты заголовка** — тело рендерится один раз, поэтому второй вариант почти
  бесплатный.
- **Карточки-вставки.** Тёмное окно с шапкой, номером шага и содержимым — скриншот
  интерфейса или строки текста, с выездом и фейдом. Своя палитра и шрифты задаются
  переменными, код править не нужно.
- **Дорожка.** Тема → сценарий → съёмка → монтаж → первый экран → публикация → разбор.
  Состояние заказа лежит в `zavod.json`, поэтому «а на чём мы остановились?» больше
  не вопрос. Плюс памятка съёмочного дня — её выдают до съёмки, а не после.

**Чего он не делает:** не переписывает речь синтезом (подмена голоса слышна — переснимайте
дубль), не решает за вас, какую мысль выбросить, и не генерирует картинки и футажи.

**Установка:** Install у плагина «Контент-завод», или в терминале:

```
/plugin install content-zavod@whynot-skills
```

**Что нужно на компьютере:** ffmpeg — поставит мастер настройки. Расшифровка речи —
`faster-whisper` (одна строка, `pip install --user faster-whisper`). Карточки —
`pillow` и `numpy`, и только если карточки нужны: монтаж без них работает на одном ffmpeg.
Взгляд в камеру умеет мериться по зрачку, но этот измеритель — только для macOS;
без него работает всё остальное.

**Сколько это «весит» в разговоре:** постоянно в контексте висят только описания —
около **1 000 токенов** на весь набор (`claude plugin details content-zavod` покажет
свежую цифру). Сам навык читается, только когда сработал: от 1 000 токенов у
распределителя до 3 800 у монтажа.

**Как пользоваться** — своими словами:

> настрой завод

> собери ролик из этой записи

> убери паузы, я записала три дубля

> поставь карточку на эту фразу

> проведи меня по шагам — на чём мы остановились?

## Как обновиться

Навыки дописываются: правится метод, добавляются инструменты. У вас лежит тот срез,
который был на момент установки, — обновление приходит только по вашей команде.

**В приложении:** Customize → Plugins → Update у плагина «Агент по монтажу».

**В терминале** — две команды, сначала обновляется список, потом сам плагин:

```
claude plugin marketplace update whynot-skills
claude plugin update montazh@whynot-skills
```

После второй перезапустите Claude Code — иначе старая версия останется в уже
открытых сессиях. Проверить, что приехало: `claude plugin list`.

**В Codex** — запустите установщик снова, он перезапишет навыки:

```
curl -fsSL https://raw.githubusercontent.com/LenaWhynot/whynot-skills/main/install-codex.sh -o install-codex.sh && bash install-codex.sh
```
