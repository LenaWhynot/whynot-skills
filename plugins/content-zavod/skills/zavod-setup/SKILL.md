# Мастер первого запуска

Твоя работа — довести человека до **первого выпущенного ролика**, а не до «всё установлено».
Пока ролик не собран на его материале, настройка не закончена.

Идёшь по шагам и отчитываешься после каждого. Вопросы задаёшь по одному.

## Шаг 1. Посмотреть, что уже есть

```bash
bash "${CLAUDE_PLUGIN_ROOT}/skills/zavod-setup/bin/check-env.sh"
```

## Шаг 2. Поставить, чего нет

**ffmpeg — сам, не отправляя человека в терминал:**

```bash
bash "${CLAUDE_PLUGIN_ROOT}/skills/zavod-setup/bin/setup-ffmpeg.sh"
```

Скачивает две программы в свою папку `~/.whynot-bin`, **без Homebrew и без пароля
администратора**, ничего системного не трогает.

**Python-пакеты** — одной строкой, и скажи вслух, что это ставится один раз:

```bash
python3 -m pip install --user faster-whisper pillow numpy
```

`faster-whisper` нужен для расшифровки речи (первый запуск скачает модель, около 500 МБ
для `small`), `pillow` и `numpy` — только для карточек-панелей. Монтаж без панелей
работает на одном ffmpeg.

## Шаг 3. Спросить про материал — по одному вопросу

1. Что снимаем: говорящая голова, скринкаст с озвучкой, съёмка процесса без слов?
2. Куда публикуем: Instagram, TikTok, YouTube, Telegram?
3. Есть ли уже отснятый файл, на котором можно прогнать весь путь? (Если нет — попроси
   записать один дубль на 20–30 секунд прямо сейчас, вертикально.)

Ответы запиши в `zavod.json` в папке заказа — дальше по ним работает навык `zavod-flow`.

## Шаг 4. Завести папку заказа

```bash
mkdir -p ~/Movies/zavod/проба/raw && cd ~/Movies/zavod/проба
export ZAVOD_WORK="$PWD"
# положить туда файл человека
```

Скажи человеку, где эта папка и что в ней лежит. Он должен уметь найти её без тебя.

## Шаг 5. Прогнать весь путь на его файле

По навыку `reel-from-take`: опись → дорожки → расшифровка → карта речи → уплотнение →
сборка → звук. Если в ролике есть шаги или интерфейс — добавь одну карточку через
`panels-graphics`, чтобы человек увидел, как это выглядит.

**Покажи результат и спроси, что не нравится.** Первая правка почти всегда про темп или
про громкость — это нормально и лечится параметрами, а не пересъёмкой.

## Шаг 6. Сказать, что дальше

- как звать завод словами: «проведи меня по шагам», «собери ролик из этой записи»,
  «поставь карточку на эту фразу»;
- где лежит папка заказа и что такое `zavod.json`;
- что публикация — отдельный шаг, и если нужного навыка нет, ролик выкладывается руками.

## Чего не делать

- Не просить пароль администратора. Всё ставится в домашнюю папку.
- Не оставлять человека с командой в руках: команды выполняешь ты.
- Не объявлять настройку законченной без собранного ролика.
- Не ставить всё «на будущее»: `pillow` и `numpy` не нужны, пока человек не захотел панели.
