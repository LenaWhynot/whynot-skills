# Ролик из дубля с речью

Человек записал себя на камеру — один дубль или несколько подходов к одной мысли.
Задача: отобрать, вычистить и собрать так, чтобы смотрелось плотно.

Порядок жёсткий: **сначала речь и звук, потом графика.** Графика поверх рыхлой речи —
выброшенная работа: любая правка тайминга ломает все панели и субтитры.

## Рабочая папка заказа

Путь — в `ZAVOD_WORK`, иначе текущая папка. Структура складывается по ходу:

```
raw/<дубль>.mp4       исходники, как с камеры
audio/<дубль>.wav     дорожки моно 16 кГц — по ним считается речь
tc/<дубль>.json       расшифровка с пословными таймкодами
probe.json            опись материала
energy.json           карта речи: блоки, пауза, порог
raw-clean/<дубль>.wav почищенный звук, если делали (см. «Звук»)
fixes.json            правки расшифровки: {"как слышит": "как надо"}
plan.json · spec.json  что собираем (форматы ниже)
```

## Порядок работы

```bash
S="${CLAUDE_PLUGIN_ROOT}/skills/reel-from-take"
export ZAVOD_WORK="$PWD"            # папка заказа
command -v ffmpeg >/dev/null || bash "${CLAUDE_PLUGIN_ROOT}/skills/zavod-setup/bin/setup-ffmpeg.sh"
```

**1. Опись и дорожки.**

```bash
python3 "$S/bin/prepare.py"
```

**2. Расшифровка** (нужен `faster-whisper`, ставится одной строкой — скрипт скажет):

```bash
python3 "$S/bin/transcribe.py"
```

**3. Карта речи и дубли.**

```bash
python3 "$S/bin/energy.py"              # блоки речи, пауза, порог на клип
python3 "$S/bin/takes.py" дубль1 дубль2 # что где сказано, с таймкодами
python3 "$S/bin/tempo.py"               # темп речи — чем выбирать дубль
```

**4. Уплотнение** — паузы между фразами и внутри них:

```bash
python3 "$S/bin/micro.py" дубль1 12.4 18.9   # RMS окном 0,05 с: где резать внутри фразы
python3 -c "import sys; sys.path.insert(0,'$S/bin'); from densify import densify; \
            print(densify('дубль1', [[12.4,18.9]], ignore_gaze=True))"
```

**5. Сборка** по `plan.json` + `spec.json` (форматы ниже):

```bash
python3 "$S/bin/assemble.py" plan.json spec.json
python3 "$S/bin/finish.py" черновик.mp4 готово.mp4    # шумодав, −14 LUFS, фейды
```

Панели и карточки поверх готового тела — навык `panels-graphics`.

## Отбор дубля: по темпу, а не на слух

**`tempo.py` считает слова только внутри блоков речи и схлопывает повторы.** На реальной
съёмке два дубля одной темы дали **197 и 168 слов/мин** — разница слышна сразу, хотя по
смыслу дубли одинаковые. Медленный дубль означает переделку всего монтажа, поэтому
выбирать надо до сборки, а не после.

⚠️ **Считать слова по сырому транскрипту нельзя.** Whisper на молчании галлюцинирует:
43 секунды тишины дали 30 повторов одной фразы и завысили темп вдвое. Отсюда фильтр
галлюцинаций в `tempo.py` — не убирать его.

## Чистка речи: порядок и границы

1. паузы между фразами — по карте RMS (`energy.py`);
2. **паузы ВНУТРИ фразы** — окно 0,05 с (`micro.py`, `densify.py`). Их слышно, и их
   замечают отдельно от «длинных» пауз;
3. фальстарты («Как?» перед фразой), оборванные дубли, повтор одного слова;
4. кадры, где взгляд ушёл (если мерили взгляд).

**Резать паузы, а не смысл.** «Убери паузы в этом месте» — это не разрешение выбросить
половину фразы. Блок продолжается, из него уходит тишина. Чтобы укоротить содержание,
нужна отдельная просьба.

⚠️ **Ложный старт внутри одного блока речи виден только в готовой сборке.** Фраза,
записанная дважды подряд с паузой 0,25 с, у whisper выходит ОДНИМ предложением и уезжает
в монтаж незамеченной. Лечится проверкой готового тела кусками по 1,5–3 с, а не полным
прогоном: на длинном файле whisper сглаживает повторы и молча пропускает фразы.

⚠️ **Голос не подменять синтезом.** Если в речи нужно поменять слово — переснять этот
дубль или обойти монтажом. Синтез поверх живой записи слышен, проверено.

## Звук

**Глухой звук — это избыток низа, а не нехватка верха.** Замер против хорошего образца:
у него низ 80–250 Гц на −5,0 dB, у «бубнящей» записи −3,4. Рабочая цепочка:

```
highpass=f=85, afftdn=nf=-25, eq 200 Гц −2.5, eq 3500 Гц +3, highshelf 8500 +3
→ loudnorm=I=-14
```

**Без компрессора** — он жмёт динамику до 5,5 dB там, где у образца 9,6, и звук
становится плоским. Мелочи, которые экономят круг правок:

- `afftdn` с `tn=1` чистит **хуже**, чем без него;
- эффект мерить как отношение сигнал/шум, а не по шумовому полу: `loudnorm` поднимает
  громкость обратно и портит метрику;
- резкий старт дорожки читается как щелчок — `afade=t=in:st=0:d=0.10`.

**Внешняя чистка звука даёт больше, чем свой шумодав.** Замер на живом материале через
Adobe Podcast Enhance (бесплатно, но руками, через браузер): фон −58,4 → **−81,9 dB**,
отношение сигнал/шум 24 → **57 dB**. Свой фильтр столько не даёт и на пределе съедает
согласные. Побочная выгода важнее цифр: **на чистой дорожке уплотнение видит настоящую
тишину** — на грязной фон держит уровень, и паузы внутри фраз просто не опознаются.

```bash
python3 "$S/bin/enhance_audio.py" export дубль1        # → enhance-in/дубль1.mp3
#   → прогнать файл через внешнюю чистку, скачать результат
python3 "$S/bin/enhance_audio.py" ingest дубль1 ~/Downloads/enhanced.wav
python3 "$S/bin/enhance_audio.py" status
```

`ingest` кладёт дорожку в `raw-clean/<дубль>.wav` и выравнивает длину под исходник
с точностью 0,3 с — планы считаны по таймкодам исходника, сдвиг ломает всё.
Дальше ничего делать не надо: `assemble.py` сам берёт звук из `raw-clean/` и
**переключается на лёгкую цепочку** (highpass + мягкий вырез 200 Гц + `loudnorm`).

⚠️ **Не гонять свой шумодав поверх внешней чистки** — двойная обработка даёт
«телефонный» голос. Поэтому цепочка переключается, а не дополняется.

## Взгляд в камеру — опционально и только на macOS

Если важно, чтобы в кадре был взгляд в камеру, взгляд надо **мерить по зрачку, а не по
повороту головы**: голова прямо, а глаза скошены — это видно, и это пропускает любой
детектор по yaw/pitch. Рабочее правило: смещение зрачка от центра глазной щели,
`score = max(|dx−base|/0.08, |dy−base|/0.15) ≤ 1.0`, плюс `eyeOpen < 0.15` = моргание.
База считается по кадрам с прямой головой, а не медианой по всему клипу — иначе, если
человек подолгу смотрит в заметки, фильтр съедает весь материал.

Измеритель зависит от Apple Vision, то есть работает только на macOS. **Без него всё
остальное работает**: вызывайте уплотнение с `ignore_gaze=True`, и в `gaze/` ничего не
нужно. Отдельный случай — **чтение с экрана**: там взгляда в камеру нет ни в одном дубле,
и это нормально. Берите `ignore_gaze=True` и закрывайте место панелью со скриншотом.

Границы кусков не ставить на моргание — на склейке это заметно.

## Хук и субтитры

- **Хук — крупно и в начале**, отдельным текстом. Он не обязан дословно повторять речь.
- **Субтитры — пословные**, по таймкодам из `tc/`. Кегль мельче хука.
- Если хук ложится на светлый кадр, буквы «плывут». Притемнять весь кадр нельзя —
  выглядит грязно; кладите градиент от прозрачного к тёмному к низу (`hook_shade` в spec).
- Слова, которые ваш whisper слышит неверно, не правьте руками в каждом файле —
  заведите `fixes.json` в папке заказа: `{"как слышит": "как надо"}`.
- Финальный призыв в конце ставить тем же крупным кеглем, что хук: мелкий в конце не читают.

## Форматы plan.json и spec.json

`plan.json` — что именно собираем:

```json
{
  "body": [
    {"src": "дубль1", "in": 12.40, "out": 18.90},
    {"src": "дубль1", "in": 24.10, "out": 30.05}
  ],
  "hooks": [
    {"id": "a", "src": "дубль2", "in": 2.10, "out": 5.40,
     "lines": ["Я записала это с третьего раза", "и вот что поняла"]},
    {"id": "b", "src": null, "lines": ["Три дубля — и всё равно пауза"]}
  ]
}
```

- тело рендерится **один раз**, дальше каждый заголовок получает свои субтитры и панели —
  так A/B-варианты стоят почти ничего;
- `src: null` — вариант вообще без снятого заголовка, только текст на экране;
- `"pieces": [[in,out],...]` у заголовка — несколько кусков (так вырезается пауза внутри
  самого заголовка);
- `"drop": [0,2]` — номера кусков тела, не нужных именно в этом варианте (когда тело
  повторяет мысль из заголовка).

`spec.json` — раскладка панелей и экранного текста. **Тайминги отсчитываются от начала
ТЕЛА, без заголовка** — сдвиг на длину конкретного заголовка скрипт делает сам.

Собрать один вариант: `assemble.py plan.json spec.json a`.

## Границы

- Навык не решает, что оставить в ролике по смыслу. Он убирает мусор; «эта мысль лишняя» —
  решение человека. Спрашивайте, а не выбрасывайте молча.
- Не смешивать в одном ролике этот конвейер и внешние рендеры моушен-графики:
  константы у них разные, и стык будет виден.
- Не обещать «поправим слово в речи» — см. про синтез выше.
