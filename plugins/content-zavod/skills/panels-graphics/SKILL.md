# Карточки-панели поверх ролика

Панель — тёмное окно с шапкой, номером шага и содержимым: скриншотом интерфейса или
строками текста. Выезжает снизу, строки появляются по одной, уходит фейдом.

**Порядок нерушим: графика идёт последней.** Любая правка тайминга речи ломает все
панели, поэтому тело ролика должно быть уже принято.

⚠️ **Вырезал слово в теле — пересчитай ВСЕ тайминги панелей.** Тело укоротилось, и
каждая панель после места реза теперь стоит не там. Это самая частая причина
переделки всей графики.

## Что рисовать

```bash
S="${CLAUDE_PLUGIN_ROOT}/skills/panels-graphics"
python3 -m pip install --user pillow numpy      # нужны только здесь
```

**Статичные панели** — когда хватает появления с фейдом:

```bash
python3 "$S/bin/overlay_panels.py" тело.mp4 готово.mp4 panels.json
```

`panels.json` — список готовых PNG с окнами показа:

```json
[{"file": "p1.png", "w": 1040, "h": 520, "start": 3.4, "end": 8.0}]
```

**Анимированные панели** — корпус выезжает, строки проявляются по одной:

```bash
python3 "$S/bin/build_anim.py" тело.mp4 готово.mp4 panels-spec.json
```

```json
[
  {"n": "p1", "title": "Новый проект", "step": "01", "t": [3.35, 8.05],
   "shot": {"file": "img/01.png", "box": [60, 40, 1560, 420]}},

  {"n": "p2", "title": "INSTRUCTIONS.md", "step": "02", "t": [8.50, 15.25],
   "lines": [["ты мой личный ассистент", "acc"],
             ["разбирай почту каждый день", "norm"],
             ["# это комментарий", "mut"]]}
]
```

Стили строк: `acc` — акцентная, `norm` — обычная, `mut` — приглушённая.
`box` — рамка обрезки скриншота `[left, top, right, bottom]`: берите из скриншота
только то место, о котором речь, а не весь экран.

## Где панель можно ставить, а где нельзя

- **Панель всегда ВНИЗУ кадра и на всю ширину.** Сверху она перекрывает голову
  говорящего, и ролик рассыпается.
- **Верхняя половина кадра — зона лица**, оверлеям там не место.
- **Держать панели дальше 80 px от кромки кадра.** Часть площадок режет края при
  перекодировании, и прижатый к краю угол панели обрезается.
- **Правый верхний угол по умолчанию не занимать** — там обычно живёт список шагов или
  счётчик, если он есть в вашем шаблоне.
- **Субтитры ставить ВЫШЕ панели**, иначе они лезут друг на друга: панель с якорем
  внизу и высотой 500 px занимает всё до 1340, субтитры должны быть над этой границей.

## Стиль: своя палитра без правки кода

Палитра и шрифты берутся из окружения — код трогать не нужно:

```bash
export PANEL_INK=131517       # корпус карточки
export PANEL_HEAD=212325      # шапка
export PANEL_PAPER=f2efe6     # текст
export PANEL_ACCENT=e0db66    # акцент: бейдж шага, акцентная строка
export PANEL_MUTED=969896     # приглушённый текст
export PANEL_FONT_MONO=/path/to/mono.ttf
export PANEL_FONT_SANS=/path/to/sans.ttf
```

Ещё крутится: `PANEL_FPS`, `PANEL_ANIM` (длительность выезда, по умолчанию 1,1 с),
`PANEL_Y_BOTTOM` (низ панели в кадре, 1830), `PANEL_WIDTH` (1040), `FRAME_WIDTH` (1080),
`PANEL_FADE` (0,22 с).

Шрифты ищутся сами: сначала переменная, потом типовые пути macOS, Linux и Windows.
Если не нашлось ни одного — PIL нарисует своим встроенным, будет некрасиво, но не упадёт.

## Правила, которые экономят круг правок

- **Правка применяется к КЛАССУ объектов, а не к тому, что было на экране.** Сказали
  «панели ниже» — значит ниже становятся все панели ролика, включая те, которых в этом
  варианте нет. Иначе следующий вариант приносит тот же дефект.
- **Уже отправленные ролики не переделывают.** Новое правило — для новых роликов;
  переcборка принятого стоит дороже, чем выгода от исправления.
- **Скриншот в панели должен читаться на телефоне.** Обрезайте до одного элемента
  интерфейса. Целый экран в панели 1040 px шириной — это нечитаемая мозаика.
- **Панель живёт столько, сколько о ней говорят.** Появилась раньше речи — зритель
  прочитал и заскучал; исчезла раньше — не успел.

## Границы

- Навык не монтирует речь и не чинит звук — это `reel-from-take`.
- Не рисует брендовые заставки и кинетическую типографику: это другой класс задач,
  и для него нужен отдельный рендер.
- Панели поверх непринятого тела — выброшенная работа. Сначала тело.
