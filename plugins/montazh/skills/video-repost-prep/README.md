# «Дубль два»: подготовка своего видео к повторной публикации

Локальный навык и скрипт из наработок проекта «Дубль два». Подходит для собственного видео, когда нужны несколько вариантов одного файла. В комплекте инструкция для ИИ-агента и существующий Bash-скрипт.

Скрипт удаляет переносимые метаданные, немного обрезает и масштабирует кадр, меняет яркость, насыщенность и скорость; при наличии звука перекодирует его. Дополнительные флаги включают более сильную обработку, сдвиг высоты звука, зеркало и ограничение длительности. Параметры зависят от номера копии. Это не гарантирует, что площадка примет файл или даст ему охват.

## Запуск без ИИ

Нужны Bash, FFmpeg с ffprobe и bc. Проверка установленных программ:

```bash
command -v bash ffmpeg ffprobe bc
```

Скачайте этот репозиторий и перейдите в папку навыка:

```bash
git clone https://github.com/LenaWhynot/whynot-skills.git
cd whynot-skills/plugins/montazh/skills/video-repost-prep
```

Из этой папки:

```bash
bash scripts/unique-video.sh /path/to/video.mp4 3 /path/to/output
STRONG=1 PITCH=1 bash scripts/unique-video.sh /path/to/video.mp4 3 /path/to/output
```

Результаты появятся в `/path/to/output/video-unique/`. При повторном запуске в ту же папку одноимённые результаты перезаписываются. Выбирайте новую выходную папку для каждого прогона. Для первого прогона достаточно трёх копий; большое число копий или маленький исходный кадр может сделать crop недопустимым. Для видео без аудио оставьте `PITCH=0`.

Посмотрите готовые файлы перед публикацией: кроп может задеть подпись, а зеркало переворачивает экранный текст. Исходник не меняется. Видео обрабатывается на компьютере; скрипт ничего не отправляет в интернет.

## Использование как навыка

Папка `video-repost-prep/` содержит `SKILL.md` и исполняемый скрипт. Передайте её своему ИИ-агенту и попросите прочитать `SKILL.md`; если клиент поддерживает локальные навыки, разместите всю папку в его каталоге навыков. Скрипт должен оставаться по относительному пути `scripts/unique-video.sh`. Этот экспорт не устанавливает и не активирует навык автоматически.

Пример запроса: «Подготовь три варианта моего ролика для повторной публикации. Исходник здесь, результат сохрани в отдельную папку».

## Что в этом экспорте

В инструкции сохранена исходная методика; утверждения о поведении площадок основаны на опыте автора и не являются проверенной спецификацией алгоритмов. Полная очистка всех возможных полей контейнера отдельно не подтверждена.

Отдельная лицензия этого навыка пока не указана; условия повторного распространения уточняйте у автора.
