# Рельс: Telegram напрямую

**Самый дешёвый рельс из всех и единственный полностью бесплатный для Telegram.**
Ни сервиса, ни сервера, ни абонентской платы, ни лимита постов. Свой бот публикует
в свой канал — это штатная и разрешённая возможность Telegram, а не обходной путь.

Берём его всегда, когда нужен Telegram. **Postiz ради одного Telegram не нужен:**
там либо свой сервер, либо от $29/мес, а здесь ноль.

## Настройка — один раз, пять минут

1. В Telegram написать **@BotFather** → `/newbot` → он выдаст токен.
2. Добавить бота **администратором** в свой канал, с правом публикации.
3. Вписать два значения в `~/.config/whynot/telegram.env`:

```
TG_BOT_TOKEN=123456:AA...
TG_CHAT_ID=@moy_kanal
```

Файл создай сам и поставь права `600`. **Токен в переписку не проси и не показывай** —
человек вставляет его в файл своими руками. Прочитать файл, чтобы «проверить», тоже не надо:
для проверки есть `--check`.

## Проверка и публикация

```bash
bash "${CLAUDE_PLUGIN_ROOT}/skills/video-to-socials/bin/to-telegram.sh" --check
```

Отвечает именем бота и названием канала, ничего не отправляя. Это и есть доказательство,
что рельс готов — не галочка, а живой ответ Telegram.

```bash
bash "${CLAUDE_PLUGIN_ROOT}/skills/video-to-socials/bin/to-telegram.sh" рилс.mp4 "подпись"
```

Публикует сразу. Подпись необязательна.

## Что важно знать заранее

- **50 МБ на файл.** Вертикальный рилс на 25–35 секунд обычно 5–20 МБ, влезает
  с запасом. Больше — пережать или выложить руками. Скрипт проверяет сам и не даёт
  начать заведомо проигранную загрузку.
- **1024 знака на подпись к медиа.** Длиннее — отправить текст отдельным сообщением
  следом за роликом.
- **Расписания нет.** Bot API публикует в момент вызова. Нужно «в 19:00» — либо
  человек зовёт тебя в это время, либо этот пост идёт другим рельсом.
- Формат ролика Telegram не различает: рилз, сторис и пост — всё это просто видео.
- Файл в Google Drive перекладывать не нужно — бот забирает его прямо с диска.

## Чего не делать

- Не публиковать без «да» — здесь особенно, потому что отправка **мгновенная**
  и отменить её нельзя, только удалить пост после.
- Не писать токен в код, в переписку, в `состояние.md` и в git.
- Не предлагать этот рельс для чужих каналов: бот должен быть админом, а значит
  канал должен быть человека.
