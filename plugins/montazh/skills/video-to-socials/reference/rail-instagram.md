# Рельс: Instagram напрямую

Публикация в свой Instagram через Graph API, без сервиса-посредника.
**App Review не нужен** — приложение живёт в режиме разработки, ты даёшь своему
аккаунту роль Instagram Tester и постишь к себе.

Что это даёт против Metricool: **50–100 постов за сутки вместо 20 в месяц** и
независимость от чужого сервиса. Чем платишь — двумя вещами ниже, и обе реальные.

## Цена №1: токен живёт 60 дней

Главное, что нужно понять до настройки: **пропустил срок — обновить уже нельзя.**
Не «сделаю завтра», а «прохожу авторизацию заново через браузер».

Поэтому сторож ставится сразу, а не потом:

```bash
bash "${CLAUDE_PLUGIN_ROOT}/skills/video-to-socials/bin/ig-token.sh" --status
bash "${CLAUDE_PLUGIN_ROOT}/skills/video-to-socials/bin/ig-token.sh" --refresh
bash "${CLAUDE_PLUGIN_ROOT}/skills/video-to-socials/bin/ig-token.sh" --schedule
```

`--schedule` ставит обновление **раз в неделю**, а не раз в 60 дней. Это нарочно:
пропущенные запуски (мак спал, не было сети, человек уезжал) тогда ничего не ломают —
запас всё равно восемь недель.

**Проверяй `--status` перед каждой публикацией.** Осталось меньше десяти дней —
скажи человеку и обнови сейчас, не жди падения.

⚠️ У покупателя мак может простоять выключенным месяц. Расписание этого не спасёт.
Поэтому при долгом перерыве первым делом смотри `--status`, а не лезь публиковать.

## Цена №2: Meta скачивает файл сама, по публичной ссылке

Локальный файл Instagram не принимает вообще. Нужна **прямая ссылка на сам файл**,
которую откроет кто угодно без входа.

Ссылка на страницу Google Drive (`drive.google.com/file/d/.../view`) **не годится** —
по ней отдаётся HTML-страница, а не видео. Скрипт это ловит и говорит прямо.

Куда класть файл, по убыванию надёжности:

| Способ | Кому подходит | Замечание |
|---|---|---|
| Свой сайт или хостинг | у кого он есть | самый надёжный: ссылка постоянная и своя |
| Объектное хранилище (S3 и подобные) | кто не боится настройки | копейки за трафик |
| Временный туннель к своей папке | продвинутым | **не проверено**, см. ниже |

⚠️ **Про туннель честно.** Идея — поднять `cloudflared` на локальную папку и дать
Meta временный адрес на минуту публикации. Идея рабочая по устройству, но
**живьём она не подтверждена**: проверить не удалось. Не подавай её человеку
как готовый путь и не строй на ней настройку, пока сам не увидишь, что файл
скачивается снаружи.

**Нет публичного хостинга — этот рельс не для этого человека.** Тогда Metricool:
он забирает файл из привязанного Google Drive и хостинг решает за тебя.
Это, а не только токены, вторая причина, по которой он существует.

## Настройка

1. Instagram переключить на **профессиональный** аккаунт (бизнес или автор).
2. На developers.facebook.com завести приложение, **оставить в режиме разработки**.
3. Дать своему аккаунту роль **Instagram Tester** и принять её в Instagram.
4. Получить долгоживущий токен и записать в `~/.config/whynot/instagram.env`:

```
IG_USER_ID=17841400000000000
IG_ACCESS_TOKEN=IGQ...
```

5. Сразу же `--refresh` (проставит срок) и `--schedule`.

Файлу поставить права `600`. **Токен в переписку не проси и не показывай.**

## Публикация

```bash
bash "${CLAUDE_PLUGIN_ROOT}/skills/video-to-socials/bin/to-instagram.sh" --limit
bash "${CLAUDE_PLUGIN_ROOT}/skills/video-to-socials/bin/to-instagram.sh" "https://…/rils.mp4" "подпись"
```

Скрипт сам создаёт контейнер, ждёт, пока Meta обработает видео, и публикует.
`--limit` спрашивает у самой Meta, сколько постов ещё можно за сутки — **бери
цифру оттуда, а не из документации**: Meta называет разные числа в разных местах.

## Чего этот рельс не умеет

- **Расписания нет.** Graph API публикует в момент вызова, как и Telegram.
  Нужно «в 19:00» — либо тебя зовут в это время, либо этот пост идёт через Metricool.
- **PNG не принимается** по ссылке — только JPEG. Видео — MP4/MOV.
- Подпись — до 2200 знаков.
- **TikTok этим путём не закрывается вообще.** Неаудированное приложение TikTok
  публикует только приватно. Публичный пост в TikTok — только через сервис,
  прошедший аудит.
