# Claude Edit — что есть и как этим пользоваться

Одна страница. Подробности: метод и гейты — скилл `claude-edit-reel`,
рабочие детали — `README.md` рядом.

## Что это

Конвейер «один дубль с речью → вертикальный ролик с моушен-графикой»:
на каждую произнесённую фразу своя карточка, караоке-сабы по словам,
каунт-апы на цифрах, звук на словах, A/B-хуки из одного мастера.

## Что уже собрано

| Слой | Где | Состояние |
|---|---|---|
| Кропы, звук, транскрипт по словам | `scripts/claude-edit/prep.sh` | проверено на живом файле |
| Караоке-чанки из транскрипта | `scripts/claude-edit/chunk.mjs` | генерируется, руками не пишется |
| Композиция: 4 режима, 8 карточек | `src/claude-edit/` | рендерит MP4 1080×1920 |
| Словарь движения | `src/claude-edit/motion.ts` | пружины, вход, тряска, прорисовка |
| Темы (палитра + шрифт + вес) | `src/claude-edit/themes.ts` | `editorial`, `neon-pink` |
| Звуковой кит, 13 звуков | `scripts/claude-edit/build-sfx-edit.py` | свой синтез, CC0 |
| Расстановка ударов | `src/claude-edit/sfx.ts` | на слово, не на такт |
| Витрина | `public/showreel/` | обе темы отрендерены |

## Три команды, которые нужны на практике

```bash
# 1. из дубля → кропы, звук, транскрипт, чанки
./scripts/claude-edit/prep.sh ~/путь/дубль.mov <slug>

# 2. раскадровка — единственное, что пишется руками
cp src/claude-edit/storyboard.example.json public/<slug>/storyboard.json

# 3. контактный лист → потом рендер
npx remotion still  ClaudeEdit out/qa/<slug>-90.png --frame=90 --props='{"slug":"<slug>","theme":"editorial","captions":null,"storyboard":null,"showVideo":true,"sfx":true,"musicBed":true}'
npx remotion render ClaudeEdit out/<slug>.mp4 --codec=h264 --crf 23 --props='{"slug":"<slug>","theme":"editorial","captions":null,"storyboard":null,"showVideo":true,"sfx":true,"musicBed":true}'
ffprobe out/<slug>.mp4      # проверять ФАЙЛ, а не лог рендера
```

## Что правится руками, а что нет

- **Руками:** `storyboard.json` (это и есть монтаж) и имена/термины в `audio16k.json`.
- **Никогда руками:** `captions.json` — перегенерить `chunk.mjs`.
- **Тайминги в транскрипте не трогать** даже когда правишь слова.

## Режимы кадра и карточки

`split` (рабочая лошадь) · `solo` · `fullhim` · `full` — **не больше трёх раз за ролик**.

`countup` · `stamp` · `beforeafter` · `list` · `takeover` · `proof` · `shot` · `cta`.
`shot` — настоящий скриншот в белой карточке, `highlight` в процентах обводит нужное место.

Правила без обсуждения: каждая цифра — каунт-ап, каждый список выскакивает по словам,
CTA в последних трёх секундах, в `full` входим жёстким срезом.

## Смена стиля

```bash
--props='{"theme":"neon-pink", ...}'
```

Тема задаёт палитру, шрифт, насыщенность (`wHead` / `wUi`), радиус кнопки, капс и цвет
текста поверх акцента. Карточки при этом не трогаются. Новая тема — снять цвета
**пипеткой с референса** (Pillow, топ цветов области кадра) и вписать в `THEMES`.

## Звук

`python3 scripts/claude-edit/build-sfx-edit.py` → `public/claude-edit-sfx/`
(13 звуков + `manifest.json` + `kit-demo.wav` для приёмки на слух).
Синтез numpy с нуля — ключ ElevenLabs не нужен, страйк невозможен.
Флаги композиции: `sfx` (удары) и `musicBed` (`public/sfx/pad.wav` на 0.10).

⚠️ Старый кит `public/sfx/` нормализован вразнобой (`tick.wav` −31 dBFS) — в Claude Edit
брать только новый.

## Главное правило работы

**Смотреть кадры, а не логи.** Все баги этого кита нашлись на контактном листе и ни один —
перечитыванием кода: карточка чёрным по чёрному, слово, перенесённое посреди себя,
карточка, не влезшая в баннер, штамп поверх подписи, тёмный текст на розовой кнопке.
