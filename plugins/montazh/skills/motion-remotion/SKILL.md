# Моушен-графика отдельным слоем

Есть два уровня графики, и разница в цене:

| | Чем | Когда |
|---|---|---|
| **простая** | `panels-graphics`, `broll-library` — ffmpeg + PIL | карточки, плашки, вставки со скриншотами. Быстро, ничего не ставить |
| **сложная** | этот навык — Remotion | карточка на каждую фразу, караоке по словам, счётчики, анимация по буквам |

**Начинайте с простой.** Сложная нужна, когда человек прямо просит «как у монтажёров»
и готов поставить Node.js.

## Установка — отдельной командой, в наборе Remotion не лежит

```bash
bash "${CLAUDE_PLUGIN_ROOT}/skills/motion-remotion/bin/setup-remotion.sh" ./motion
```

Скрипт разворачивает проект рядом с заказом, копирует туда готовые композиции из набора
и **скачивает Remotion сам** (первый раз несколько минут и около 700 МБ). Нужен Node.js —
если его нет, скрипт скажет и остановится.

⚠️ **Лицензия, и её надо сказать вслух человеку.** Remotion бесплатен для физических лиц
и компаний **до 3 сотрудников**; компаниям больше нужна платная Company License. Решение
принимает человек — проверить и купить за него нельзя. Остальные навыки набора таких
требований не имеют и работают на ffmpeg.

## Как это работает

Remotion **не монтирует видео**. Он рисует **прозрачный слой** — ProRes 4444 с альфой,
который потом кладётся на готовый футаж одной командой ffmpeg. Исходники в проект
Remotion не копируются никогда, иначе на каждый ролик уезжают гигабайты.

```bash
cd motion
npx remotion studio                       # посмотреть и подвигать руками
npx remotion render ClaudeEdit out/overlay.mov \
  --codec=prores --prores-profile=4444    # прозрачный слой

# положить слой на готовое тело
ffmpeg -nostdin -i тело.mp4 -i motion/out/overlay.mov \
  -filter_complex "[0:v][1:v]overlay=0:0:format=auto" \
  -c:v libx264 -crf 19 -pix_fmt yuv420p -c:a copy -y готово.mp4
```

## Что внутри шаблона

```
src/ClaudeEdit.tsx   композиция ролика: собирает карточки по раскадровке
src/cards.tsx        сами карточки: типы, вход, выход, каунт-апы
src/themes.ts        темы: спокойная типографская и контрастная
src/tokens.ts        палитра — у каждого цвета одна роль
src/motion.ts        пружины и тайминги: одна физика на весь ролик
src/sfx.ts           звуковые акценты
src/Kinetic.tsx      кинетическая типографика (в ней решены русские переносы)
src/HookSubsOverlay.tsx  шаблон прозрачного оверлея под хук и субтитры
src/storyboard.example.json   пример раскадровки
src/CHEATSHEET.md    шпаргалка по типам карточек
```

**Своя палитра — в `tokens.ts`, своя тема — в `themes.ts`.** Правило важнее значений:
у каждого цвета одна роль, нет роли — нет цвета. Тему для чужого бренда снимайте
**пипеткой со скриншота**, а не подбирайте на глаз.

## Правила, которые экономят переделку

- **Вся визуальная система живёт в одном блоке токенов.** Навести тот же монтаж на другой
  бренд — это добавить тему, а не переписывать карточки.
- **Каждая цифра получает счётчик, каждый список выезжает по словам** — иначе графика
  выглядит наполовину сделанной.
- **Одна физика движения на весь ролик** (`motion.ts`): разные пружины в одном ролике
  читаются как разные ролики.
- **Контент живёт в верхней части кадра, нижняя полоса принадлежит субтитрам.**
- **Вырезал слово в теле — пересчитай все тайминги слоя.** Слой считается по таймкодам
  тела; сдвиг ломает всё.
- **Караоке-субтитры генерируются, а не пишутся руками**: в минуте речи это сотни
  переходов.

## Границы

- Навык не режет речь и не чинит звук — это `reel-from-take`.
- Не смешивать в одном ролике этот слой и простые карточки `panels-graphics`:
  тайминги и физика у них разные, стык будет виден.
- Не ставить Remotion «на будущее». Не нужен сложный слой — не ставьте: набор
  полноценен без него.
