# Формат раскладки `cut.json`

Один объект на шот, порядок в массиве = порядок в ролике.

| Поле | Обязательное | Что значит |
|---|---|---|
| `src` | да | имя исходника без расширения; прокси ищется как `proxy/<src>.mp4` |
| `ss` | да | секунда начала шота в ЭТОМ исходнике |
| `d` | да | длительность шота в секундах |
| `zoom` | нет | наезд `+0.10…+0.14`, отъезд отрицательный, `0` — без зума. Только на устойчивых шотах (тряска < 0,10) и никогда на открывашке и закрывашке |
| `frame` | нет | кроп из нативного кадра `W:H:X:Y`, соблюдая 9:16. Нужен, когда сбоку в кадр лезет лишнее |
| `kind` | нет | подпись для себя: какая стадия и зачем шот. Её печатают проверки, по ней читается раскладка |

Хронология строго вперёд: `ss` следующего шота того же исходника больше предыдущего.
Шоты одной стадии ставить кучно — с промежутками 4–6 секунд, а не вразброс по всему
её диапазону.

Образец — [`cut-format.json`](cut-format.json).
