# Instagram без логина — что откуда достаётся

Дополняет `reference.md`. Тот описывает путь через `scripts/reel_fetch.sh` (yt-dlp) для ОДНОГО
рилса. Здесь — как забрать подпись, метрики, слайды карусели и хуки с обложек, в том числе
когда разбирается не пост, а **аккаунт целиком** или несколько аккаунтов сразу.

Проверено 28.08.2026 на разборе 8 аккаунтов (adrianabubori, lekhovitskaya, alliekmiller,
brand.nat и др.).

## Главное правило: embed открывать БРАУЗЕРОМ, не curl

`https://www.instagram.com/p/<CODE>/embed/captioned/`

- **curl отдаёт JS-оболочку** — 600 КБ скриптов, ни подписи, ни цифр. Регулярки по ней ничего
  не находят. Это не блокировка, это просто нерендеренная страница.
- **Тот же URL через браузер-MCP** (`navigate` → `get_page_text`) отдаёт живьём: полный текст
  подписи, `N likes`, `View all N comments`, ник, число подписчиков. Без логина.
- Для рилса тот же URL: в DOM лежит прямой `<video src>` на CDN — вот его уже можно `curl`,
  дальше ffmpeg + whisper. То есть yt-dlp для публичных постов не обязателен.

## Хуки дословно берутся из `alt` картинок

На странице профиля (тоже без логина) Instagram сам прогоняет обложки через OCR и кладёт
результат в `alt`:

```js
Array.from(document.images).map(i => i.alt).filter(a => a && a.includes('by '))
```

→ `"Video by ALEX MANOKHIN on August 25, 2026. May be an image of text that says
'Запускаем Claude Code сессии на пробежке'."`

Текст в кавычках — **это и есть хук с обложки, дословно**. Именно то, что чаще всего просят
«выпиши дословно». Забирать как есть, не пересказывать.

Грабли OCR: дублирует слова (`GOOGLE GOOGLEFLIGHTS FLIGHTS HACKS`), путает кириллицу,
иногда отдаёт пустоту и только описание сцены (`May be an image of lipstick, cosmetics`).
Кривые пометить `⚠️OCR`, но привести: человек сам узнаёт формулировку.

## Сколько отдаётся без логина

- Профиль: **ровно 12 последних постов**. Дальше пагинация грида требует авторизации
  (`graphql/query` → `require_login: true`). Скроллом больше не выжать — не тратить на это ходы.
- `web_profile_info` даёт по этим 12: лайки, комменты, **просмотры**, полную подпись.
- Больше 12 — только веб-поиском по отдельным постам. Зеркала (imginn и подобные) закрыты
  Cloudflare-челленджем, не ломать.

## Карусель: как забрать все слайды

Логаут-страница поста грузит 1–2 слайда. Остальные догружаются кликами:

```js
for (let k = 0; k < 10; k++) {
  document.querySelector('[aria-label="Next"]')?.click();
  await new Promise(r => setTimeout(r, 1200));
  // собирать document.images с t51.82787-15 и naturalWidth > 400
}
```

Число слайдов = число элементов `[aria-label="Carousel"]`. Собранные CDN-ссылки качать
`curl`, потом `sips -Z 900` — иначе слайд 1440×1920 жрёт контекст зря.

## Несколько аккаунтов — веером агентов, каждому своя вкладка

Браузер один на сессию, поэтому в промпте агента **первым шагом** обязательно:

> Создай свою вкладку `tabs_create {foreground:false}`, дальше ВСЕ вызовы делай с этим `tabId`.

Без этого агенты перебивают друг другу навигацию. По 2 аккаунта на агента — нормально.

## Что считать метрикой

Просмотров без логина у постов-каруселей нет, у рилсов есть. Универсальный прокси —
**отношение комментов к лайкам**:

- 0.2–0.4 — обычный пост
- ≈1.0 и выше — пост с кодовым словом в комментах, это не вовлечённость, а лид-ген

Считать его всегда: он сразу показывает, где у аккаунта контент, а где воронка.
